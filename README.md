# React + Vite Project

This project was built using **React** and **Vite**.  
For backend simulation, the project uses **json-server** with a local `db.json` file.

## Tech Stack

- React
- Vite
- JSON Server

## Installation

```bash
npm install
```

## Running the Project

Start the mock backend:
```bash
json-server --watch db.json --port 3001
```
Start the frontend:
```bash
npm run dev
```
Frontend will be available at:

http://localhost:5173

Mock API will be available at:

http://localhost:3001
